# 开放注册与历史保留

上级：[[../PROJECT_MAP]] · [[Admin UI]] · [[Web History]]

## 注册与余额

邮箱验证码登录接口同时支持注册，验证成功的新账户余额为零。验证码最多尝试五次，一次性消费；沿用邮件发送限流。邀请码注册接口返回 410，旧账户和历史数据保留。

管理员通过账户 grants 接口赠送余额，输入整数分、原因和唯一请求标识。account_grants 记录操作者与前后余额，数据库触发器保证入账和记录原子提交。重复相同请求不重复赠送，不同载荷复用标识返回 409。旧订阅赠送接口停用；设备授权按账户和设备有效性判断，余额在模型调用时校验。

## 三端保存

- Web：输入和回答按同一轮创建时间保留三十天。列表、详情、模型上下文立即过滤到期内容；标题不继续引用过期消息。每小时第十七分钟分批物理清理，单次最多两千轮，下一次继续；无消息的过期对话同步清理。
- Desktop / CLI：保留隔离 CODEX_HOME 和原生会话恢复。Desktop 的本地展示索引不是云端历史，不向网页 conversations 接口同步。不修改当前本地用户文件。
- 代理只保存用量、价格快照和扣费状态，不将 Desktop/CLI 请求正文、响应或工具输出存入聊天表。

## 运维与恢复

迁移 0016 为增量新增，保留旧表。全库本地导出被自动审批拒绝，改用 D1 Time Travel 服务端恢复书签。恢复数据库属于独立运维操作，会影响恢复点之后的数据；不能把代码回滚当成数据恢复。

现有五份本地 SQL 备份检查均没有聊天 INSERT。以后不长期导出聊天正文；恢复服务端历史快照后，先运行过期过滤和清理再开放服务。托管恢复快照由 Cloudflare 自身策略控制，应用无法逐条擦除其历史快照。
