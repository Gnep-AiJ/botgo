## CI 发现与修复

- 原更新器测试依赖本机 Node/npm 路径，在 Windows 托管机失败。测试改用明确文件系统夹具；运行器支持 Node 同目录、npm_execpath 和 PATH 中的 npm JS 入口，不通过 cmd shell 启动 npm。
- npm 备用查询需要 registry 根地址，不能使用包元数据地址；真实只读查询返回 0.154.0。
- PowerShell 7 启动 Windows PowerShell 5.1 时模块发现不一致，CI 改为全程 PowerShell 5.1。
- 深目录 npm 解压触发 Windows 旧路径限制；逐条验证 ZIP 路径后，用规范反斜杠和扩展路径逐文件解压。深目录下安装、Node 复用、升级及坏哈希回退已在本地通过，修复提交 `610dfbb` 的 Windows CI 也完整通过。
- 最终 0.1.3 包再次通过本地安装/升级/坏哈希回退。测试目录、解包暂存目录和被替代的本地候选包已删除；最终候选、截图和构建缓存保留。
