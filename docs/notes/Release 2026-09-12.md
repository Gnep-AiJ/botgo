## 本地验证

- 全项目 `npm test` 和 `npm run check` 通过；CLI 共 24 项测试。
- 真实 Chrome：1440、390、360px 账户面板；无横向溢出、充值按钮可见、无脚本异常。账户与支付响应使用测试数据，不证明真实付款。
