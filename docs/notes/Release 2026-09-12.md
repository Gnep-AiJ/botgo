## 明确阻塞及恢复步骤

自动审批拒绝直接推送默认分支 main，也拒绝立即启用生产维护模式，要求明确授权默认分支更新和生产停机时段。没有执行生产 Worker 部署或 0013 迁移，也没有绕过拒绝。

得到明确授权后：核对最新 D1 状态并刷新保护备份；启用 `BOTGO_MAINTENANCE=1` 短暂维护，应用 0013，部署最终 Worker 并显式设置 `BOTGO_MAINTENANCE=0`；验证金额、CLI 固定版本下载/哈希和真实授权，再激活 CLI current manifest 与生产 Pages。最后正常更新 main，记录远程提交和部署标识。失败时先恢复可用的兼容 Worker；不要在分单位数据库上运行旧元单位 Worker。
