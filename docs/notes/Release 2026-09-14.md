# BotGo Desktop 1.3.1

## Intended release contents

- BotGo-only product copy, title-bar logo, and persistent account entry.
- Native model catalog driven by verified production routes; `GPT-5.6 Sol` has no frontend bypass.
- Authenticated, same-origin signed updater that downloads in the background after login and waits for user-confirmed restart/install.
- Removal of the retired 1.2.1-preview.9 source client.

## Required publication sequence

1. Complete local build, test, static check, and isolated Electron render.
2. Build and Authenticode-sign `BotGo-1.3.1-win-x64.exe`; record exact file size and SHA-256.
3. Configure the Sol route disabled, run the authorized two-request metered probe, and enable it only when the probe succeeds.
4. Upload the verified package to private R2, create and publish its `desktop_releases` record, then read back the authenticated current-release endpoint.
5. Delete only the exact retired 1.2.x R2 objects and release records after the new published record is proven. Preserve 1.3.0-preview.1 until a replacement is verified.
